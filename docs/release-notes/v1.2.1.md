## SwissOlly 1.2.1

A small release: FPS that recovers on its own, the version shown in Settings, and installer
names without the version in them. Settings and history carry over from 1.2.0 as they are;
install over the top.

### FPS

- **A failed start is retried.** In 1.2.0, if the FPS tracking failed to start once (at the
  first game of the day, say), FPS read "--" in every game until SwissOlly was restarted. Now it
  tries again every 5 seconds for a minute, then every 30 seconds, while the game is in front,
  and the message clears with "FPS is reading again." once it works.
- **The message says what went wrong.** "Sign out of Windows and back in" now appears only
  when your sign-in really lacks the Performance Log Users group. Otherwise it names the step
  and the Windows error, and says where the log is.
- **A short FPS log is always kept.** When FPS fails or recovers, the last 200 lines are written
  to `%LocalAppData%\SwissOlly\fps.log`, so a bug report can include it without turning any
  logging on first. It also records when a game sends no frames for 10 seconds, and whether
  other programs' frames arrive, which is how a game that hides its frames shows up.
- **Two copies no longer stop each other's FPS.** Each running copy uses its own tracking
  session, and sessions left behind by a copy that closed unexpectedly are cleaned up.

### New

- **Settings shows the version.** An About section at the end of Settings shows which
  SwissOlly this is (version, x64 or ARM64, Windows build), with **Copy version info** for bug
  reports and links to these release notes, the bug form (version and Windows filled in) and
  the source. The links open in your browser; SwissOlly itself still makes no network
  connections.

### Installer

- **Installer names have no version:** `SwissOllySetup-x64.exe` and `SwissOllySetup-ARM64.exe`.
  The link `releases/latest/download/SwissOllySetup-x64.exe` now always gets the newest one.
  Links to 1.2.0's files keep working.

### Known limitations

- **The installers are not code-signed yet,** so Windows SmartScreen may warn on first run.
  Check the download against `SHA256SUMS.txt`, then choose **More info → Run anyway**.
- **Battlefield 6 may still read "--" for FPS.** Players report the same with AMD's and
  NVIDIA's own overlays, which points at the game's anti-cheat rather than SwissOlly. The
  game's own Performance Overlay (Graphics > Advanced) shows FPS there.
- The overlay supports borderless and windowed games, not exclusive fullscreen, and looks dim
  in HDR games.
- Exact FPS needs one sign-out after installing.
