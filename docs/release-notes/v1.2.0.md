## SwissOlly 1.2.0

The first release under the SwissOlly name (previously Vaktr). Installing over Vaktr 1.0.x upgrades in place: settings, history and the startup entry carry over, from the default folder or a custom one.

### New

- **Arrange the board.** Edit layout (Ctrl+E) lets you drag panels on a 12-column grid and resize them from any edge or corner. From the keyboard, Tab to a panel, then use the arrows to move it and Shift+arrows to resize it.
- **Process popover.** The CPU Total and Memory panels list every running process, services included. Sort by highest, lowest or name, and pin processes to the chart by clicking them or pressing Enter.
- **Keeps running in the tray.** Closing the window leaves SwissOlly recording in the notification area; right-click the icon to exit. Settings can switch this to exit on close, and turn on Start with Windows.
- **One copy at a time.** Opening SwissOlly again brings the running window forward instead of starting a second collector.
- **Twelve themes,** including Obsidian (true black for OLED), Synthwave, Frost and Blossom, each previewed in Settings as a miniature of the app and checked against the WCAG AA contrast floor.
- **Neon overlay colours.** Ten neon presets beside six classic ones, any hex value, and a live preview of the overlay in Settings.

### More accurate numbers

- CPU usage and per-core load now match Task Manager (`% Processor Utility`).
- CPU clock shows the real speed, including boost, instead of the base clock.
- GPU usage adds up every process using an engine, as Task Manager does, instead of reporting the busiest single process.
- Per-process CPU and memory cover services and system processes, which showed as zero before. Memory is the private working set (Task Manager's Memory column), and CPU is measured in cycles, so short bursts are no longer missed.
- Process, thread and handle totals match Task Manager.

### Polish

- Charts leave gaps where there's no history (the PC was off or asleep) instead of drawing a line across them, mark where collection started, and show a loading state while history loads.
- Times follow your Windows regional format (12- or 24-hour, day and month order).
- Settings is grouped into Appearance, Data and history, In-game overlay, and Startup and closing, each saying when its changes take effect. Apply and Revert float at the bottom whenever something is unapplied (Ctrl+S applies), rejected values are explained there, and a lower retention asks before deleting history.
- Buttons respond instantly: Settings no longer rebuilds itself on every click, and switching time ranges takes a few milliseconds.
- Pinned processes draw beside the panel's own line, each in its own colour and named in a legend.
- On light themes, chart lines and accents are drawn in deeper shades of the same colours, so they stay readable against white.
- New text fields with selection, undo and redo, clipboard shortcuts and a right-click menu.
- Screen readers get names and roles for every button, row and field, and every control works from the keyboard.
- The window has a minimum size, and the summary strip and header adapt to narrow windows.

### Reliability

- A full disk or an unplugged storage drive stops history, not the live board. The status line says why, and saving resumes on its own.
- Corrupt or hand-edited settings fall back to safe values instead of failing to start.

### Installer

- Self-contained: .NET and the Windows App SDK runtime are included, so a clean PC needs nothing else.
- "Allow exact FPS" is now an explicit option, and uninstalling removes the Performance Log Users membership it adds (if Setup added it).
- Uninstalling also removes the startup entry. Settings and history in `%LocalAppData%\SwissOlly` are kept.
- SHA-256 checksums for both installers are attached as `SHA256SUMS.txt`.

### Known limitations

- **The installers are not code-signed,** so Windows SmartScreen may warn on first run. Check the download against `SHA256SUMS.txt`, then choose **More info → Run anyway**.
- The overlay supports borderless and windowed games, not exclusive fullscreen, and looks dim in HDR games.
- Exact FPS needs one sign-out after installing.
- Windows contrast themes aren't followed; SwissOlly always draws with its own palettes.
